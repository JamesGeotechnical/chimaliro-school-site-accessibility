Chimaliro School Site Accessibility Analysis



Overview

This project uses Geographic Information Systems (GIS) and Python to analyze school accessibility and identify potentially suitable land for school development in Chimaliro, Malawi.



\## Project Structure

\- `notebooks/`: Main Jupyter notebook containing the analysis code.

\- `data/`: Spatial datasets used in the project.

\- `outputs/`: Analysis results and interactive maps.



Technologies

\- Python

\- Jupyter Notebook

\- GeoPandas

\- Pandas

\- Shapely

\- Folium



Outputs

The project produces spatial suitability results and an interactive GIS map showing schools, roads, rivers, protected areas, and potentially suitable land.
